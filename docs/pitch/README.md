# Presentación final

La presentación del equipo está disponible en [Canva](https://canva.link/ceqim33wqulq7q9). La [copia en PDF](diapositivas.pdf) tiene diez diapositivas y sirve para presentarla sin depender de Canva. Ambas muestran el problema, el producto, la arquitectura distribuida, el manejo de fallas, resultados locales y la demostración.

La aplicación se inicia siguiendo el [README principal](../../README.md). Los datos y límites técnicos de la exposición se respaldan en el [reporte final](../reporte-final.pdf) y los [resultados medidos](../RESULTADOS_FINALES.md). Cada integrante presenta y responde preguntas sobre el funcionamiento del sistema.
