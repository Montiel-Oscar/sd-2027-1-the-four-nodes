# Amy · interfaz de extravíos

**Rama de partida:** `01-monolito`. Antes de editar: `git switch 01-monolito`, `git pull origin 01-monolito` y `git switch -c trabajo/amy-web`. En GitHub Desktop, selecciona la rama base, actualízala y crea tu rama personal.

Convierte la página inicial de esta carpeta en un formulario sencillo que funcione en teléfono y computadora. Sigue [el contrato de API](../../docs/CONTRATOS_01_MONOLITO.md): permite capturar mascota y ubicación, genera una clave de idempotencia por intento y conserva la misma clave si la red falla. Tras publicar, muestra el enlace público. Crea una vista pública que cargue el reporte por su ID.

**Entregable:** formulario usable, errores claros y página pública del reporte. Puedes trabajar con una respuesta de ejemplo mientras Oscar implementa la API, pero quita el ejemplo antes de integrar. No añadas mapa ni carga de fotos. Publica tu rama y solicita integración hacia `01-monolito`.
